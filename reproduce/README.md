# Reproducibility

Every raw file under `data/raw/` and every derived table under `data/derived/` came from a
script in this folder.

## Per-complex MD analysis (produces `data/raw/complex_analyses/{target}/{cid}/*`)

- `analyze_complex.py` — one-shot analysis for a single (target, complex_id). Reads
  `system.gro + system.top + process/gromacs.xtc` from the discovery-9 productions, writes
  `summary.json` + 6 auxiliary files. ~50 sec on 4 cores per complex.
- `run_one.sh` — SLURM wrapper (short partition, 4 CPUs, 6 GB mem, 15 min). Array-submittable.
- `ligand_chem_from_topology.py` — one-shot pass over all 270 complexes to build the RDKit
  descriptors table (`data/derived/ligand_chem.parquet`).

Array-submit example:

```bash
sbatch --array=0-269%60 --time=00:15:00 --mem=6G -c 4 -p short -J disc9 \
  --export=ALL,STRIDE=50,IFP_STRIDE=50,HB_STRIDE=50 \
  reproduce/run_one.sh
```

## Aggregation (produces `data/derived/features.parquet`)

- `aggregate_results.py` — flattens all 270 `summary.json`s into a wide table, joins
  `metadata.csv`.

## Analysis pipelines (produce the deep-research tables)

- `deep_research.py` → `deep_research_summary.csv` + `deep_research_p1/p2/p3_per_target.csv`.
  Runs all of P1 (feature-selection over sp-configs), P2 (MD → is_active), P3 (full-factorial ML).
- `gbsa_param_vs_md.py` → `gbsa_param_vs_md_correlations.csv` (v1, MD-only features).
- `gbsa_param_vs_md_v2.py` → `gbsa_param_vs_md_v2_*.csv` (MD + ligand-chem, BH-FDR-adjusted).

Run any of them under the notebook's pixi env:

```bash
cd ../env && pixi run python ../reproduce/<script>.py
```

## Hardened analyses (added after external peer review)

- `hardened_claim_b.py` → `data/derived/hardened_claim_b.csv` — panel BEDROC (Truchon-Bayly
  early-enrichment metric) of every candidate MD/chem feature under **7 conditions**: `naive`,
  `mw_resid` (MW regressed out per target), `size_resid` (MW + heavy atoms + TPSA regressed
  out), `bound_only` (drops complexes with drift or COM disp > 8 Å), `pbc_clean` (drops
  PBC-flagged trajectories via `pbc_qc.csv`), `alt_label_7` (pchembl ≥ 7 vs ≤ 5), `alt_label_6`
  (pchembl ≥ 6 vs ≤ 5). Bootstrap CI (B=5000, target-level resample) + within-target
  permutation p (B=5000). Label-derived columns (`pchembl*`, `is_active*`, `docking_score`)
  dropped from candidates. Emits `hardened_claim_b_summary.md`.
- `deep_research_wide.py` → `data/derived/deep_research_wide.csv` — wider LOTO
  (leave-one-target-out) ML sweep with **in-fold** `Pipeline(SimpleImputer + [StandardScaler]
  + estimator)` — no leakage. Models: HistGradientBoosting, RandomForest, ExtraTrees, Ridge
  (tuned α), ElasticNet, SVM-RBF (tuned C/γ), LogReg-L1/L2. Bootstrap CI + permutation p on
  panel BEDROC. Emits `deep_research_wide_summary.md`.
- `pbc_qc.py` → `data/derived/pbc_qc.csv` — per-trajectory QC flags: `max_com_jump_A`,
  `max_drift_A`, `is_pbc_artifact` (jump > 6 Å), `is_probably_unbound` (drift > 8 Å). Consumed
  by `hardened_claim_b.py` for the `pbc_clean` condition.

## Canonical baseline reconciliation

- `canonical_baselines.py` → `data/derived/canonical_baselines.csv` — single source of truth
  for the docking / GBSA-locked panel BEDROC α=20 values used across both trees. Convention:
  9-target discovery panel, missing-target imputation = 0, bootstrap B=5000 (target-level
  resample). GBSA-locked = single global-best combo `igb2_di4_salt0.15_st0.0072` (also the
  panel-mean argmax on the 9T panel; verified by the script). Consumed by upstream NB 02/04
  and downstream NB 10/16 so every "docking baseline = X" or "GBSA-locked = Y" cites the same
  value.

  Run with `--verify` to diff on-disk values against a fresh recompute:

  ```bash
  cd env && pixi run python ../reproduce/canonical_baselines.py            # write
  cd env && pixi run python ../reproduce/canonical_baselines.py --verify   # verify no drift
  ```

## Upstream reproduce scripts — `reproduce/upstream/`

The upstream-origin notebooks (`notebooks/02_md_config_provenance.ipynb` +
`notebooks/{04..13}_*.ipynb`) get regenerated by the scripts in `reproduce/upstream/`. See
`reproduce/upstream/README.md` for SLURM launcher details. Quick reference:

| Script | Regenerates |
|--------|-------------|
| `bedroc_doe.py`            | Per-(target, GBSA-combo) BEDROC α=8/20/80 (`derived/temporal/bedroc_all_combos_per_target.csv`). Feeds NB 07, 12, 13. |
| `bedroc_param_scatter.py`  | Per-combo BEDROC scatter for NB 06. |
| `temporal_convergence.py`  | Truncated-trajectory BEDROC sweep for NB 12 (`derived/temporal/temporal_bedroc_vs_time.csv`, `per_target_settling.csv`). |
| `factorial_gbsa.py`        | The 48-combo MM-GBSA rescoring recipe (writes `data/external/gbsa-study/data/raw/gbsa_dG_raw.csv`). |
| `md_configs.py`, `gen_variant_mdp.py` | Taguchi L27 GROMACS-config catalogue + `.mdp` file emitter for study 2. |
| `run_full.sbatch`, `run_variant.sbatch`, `submit_full.sh`, `submit_smoke.sh` | SLURM launchers for the productions. |

Regenerating an upstream analysis:

```bash
cd env && pixi run python ../reproduce/upstream/<script>.py
```

Then re-execute the flat notebook tree (or a subset — the upstream-origin slots are 02, 04-13):

```bash
pixi run jupyter nbconvert --to notebook --execute --inplace ../notebooks/*.ipynb
```
